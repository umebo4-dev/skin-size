# GBF スキンサイズ比較

スキンごとの画像(PNG)サイズ・CJS JSファイルサイズを収集・比較して、最も軽いスキン編成を特定する。

---
## はじめに

データや画像の読み取りしかしてないので自認セーフです。F12で見られるからゆるして。

## 構成

| ファイル | 役割 |
|---|---|
| `app.py` | Flask Webアプリ |
| `fetch_meta.py` | gbf.wiki からキャラメタ情報（属性・種族など）を取得（アプリ内「更新」から実行） |
| `skinsize.db` | SQLiteデータベース |
| `static/images/` | 収集した画像（sd/quest/raid） |

データ収集は Chrome 拡張機能（`gbf_profiler_ext`）が担当。

## セットアップ

1. Python のインストール

https://www.python.org/downloads/ から Python 3.x をインストール。  
インストール時に **「Add Python to PATH」にチェックを入れる**。

2. 必要ライブラリのインストール

コマンドプロンプトで以下を実行：

```
pip install flask requests pillow cloudscraper
```

3. Chrome 拡張機能のインストール

`gbf_profiler_ext` フォルダを Chrome の拡張機能ページ（`chrome://extensions`）で「パッケージ化されていない拡張機能を読み込む」からインストール。

4. アプリの起動

`start.bat` を右クリック →「ショートカットの作成」でデスクトップに置くと便利。

ダブルクリックで起動するとブラウザで `http://localhost:5000` が開く。

5. キャラデータの取得

アプリのナビバー「更新」からwikiデータを取得する。
属性・得意武器・種族などのフィルター機能に使用される。
新キャラを適用する場合都度更新すること。

## 計測方法
1. 主人公(ブコン)+計測したいキャラを編成
2. 拡張機能を画像計測モードにして木人に入室
 - 入室前のokボタンが出る段階で編成を、バトルに入った段階でバトル、SD、phit、キャッシュを読み込む
3. 撤退する
4. JS計測モードにしJS実行時間を計測
 - この際も一回ごとに撤退すること。キャッシュクリアするとデータが大きくなる可能性がある。

## データ収集

Chrome 拡張機能を有効にした状態でゲームのバトルに入ると自動収集される。

- **JS計測モード**: キャラアニメーションのJS実行時間を計測
- **画像計測モード**: 画像・JSファイルサイズを収集（初回はキャッシュクリア推奨）

収集されたデータは `http://localhost:5000` で確認できる。

### 収集されるデータ

| タイプ | 内容 |
|---|---|
| `sd` | SDスプライト PNG |
| `quest` | キャラ立ち絵 JPG |
| `raid` | バトル立ち絵 JPG |
| `cjs_npc` | `npc_*.js` アニメーションJS |
| `cjs_phit` | `phit_*.js` 攻撃エフェクトJS |
| `phit_png` | 攻撃エフェクト PNG |

- キャラ名はバトル開始時に自動取得
- 画像はCDNからバックグラウンドでダウンロード・WebP変換して保存

## 画面説明

### キャラ一覧
- 名前が取得済みのキャラのみ表示
- サムネイルはskin_num最小・属性最多のquest画像

### 詳細ページ

**上部3カード（最軽量まとめ）**
- SD / 編成 / バトルそれぞれの最軽量スキンを表示

**推奨モード（デフォルト）**
CJS最小のSDスキンを「推奨グループ」とし、同グループ内で編成・バトルも最軽量を選出。グループは赤枠でハイライト。

**個別モード**
SD・編成・バトルをそれぞれ独立に最軽量選出。

### 算出方法
 - JS 実行時間 キャラクターのアニメーション関数が実際に消費したCPU時間。パーフォーマンスのnミリ秒に一致。複数回計測した平均値を表示し、誤差レベルの差（10%以内）はPNGサイズで比較する。PC環境によって変動アリ。
 - PNG サイズ そのスキンの全画像ファイルサイズの合計(エフェクト含む)。属性違い（_s1~6）は平均。
 - 推奨モード JS実行時間が最小のSDスキンを推奨グループとし、そのグループ内で編成・バトルも独立に最軽量を選出。
 - 個別モード SD・編成・バトルをそれぞれ独立に最軽量を選出。
 - サブモード サブ編成時用。JSは読み込まれないためSDのPNGと編成のPNGサイズで算出。

## 診断ツール（/check）

ナビバーの「診断」から開く。

画像が表示されない場合にファイル名を入力して原因を特定できる。

```
入力例: images/raid/3040032000_04.jpg
        3040032000_04.jpg   ← ファイル名だけでも可（自動でディレクトリを探索）
```

| 診断結果 | 対処 |
|---|---|
| DBに未登録・ディスクにあり | 「DBに登録する」ボタン |
| DBに未登録・ディスクになし | ファイルを選択して「アップロード＆登録」 |
| キャラ名なし | ゲームでそのキャラのバトルをプレイしてキャラ名を取得 |
